# icons

The studio tools use one icon set: **Alchemy** by chinnan, The Noun Project
(https://thenounproject.com/browse/collection-icon/alchemy-18255/, 45 glyphs). Edson's
choice, 2026-10-20. Black glyph on transparent, 512 px, as the site serves them; the
pages show them inverted on black.

| File | Noun Project | Used for |
|---|---|---|
| `strategy.png` | *strategy* #556645 | Rascunho |
| `understand.png` | *understand* #556651 | Trilha |
| `delight.png` | *delight* #556854 | the hub (Tools): its home-screen icon and favicon |

A new studio tool picks its glyph from the same set and gets a row here. Attribution,
required under the Noun Project's free licence: "strategy / understand / delight by
chinnan from Noun Project (CC BY 3.0)". The hub footer carries it. For crisp SVGs,
download them from the icon pages with the Noun Project account (`make_icons.py`
only needs these PNGs).
